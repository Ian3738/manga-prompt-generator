# 🌸 日系動畫提示詞產生器 (Anime Prompt Studio)

> 選擇漫畫風格、日本場景、四季、故事類型，自動生成可用於 Gemini Omni、Luma、Pika 的影片提示詞。每次都是一個三幕小故事。

[![Live Demo](https://img.shields.io/badge/Live-Demo-FF6B6B?style=for-the-badge)](https://Ian3738.github.io/manga-prompt-generator/)

## ✨ 特色

- 🎨 **12 種日系風格**：吉卜力、新海誠、京阿尼、少年漫畫、少女漫畫、青年漫畫、90 年代復古、賽博龐克、機戰、水彩繪本、黑白漫畫、Q 版可愛
- 🗾 **18 個日本場景**：澀谷街頭、京都神社、富士山、北海道雪原、櫻花隧道、夏日祭典、便利商店、漁港小鎮…
- 🌸 **四季氛圍**：春櫻、夏蟬、秋楓、冬雪 — 自動帶入季節元素
- 📖 **8 種故事類型**：戀愛、校園日常、治癒系、懸疑、異世界、運動青春、妖怪傳說、賽博龐克
- 🎭 **三幕劇結構**：每個故事自動展開為三個場景，可一鍵切換不同故事弧
- 🌐 **中英雙語**：同時產出兩個版本，英文版通常 AI 識別更準確
- ✨ **角色設定**：可自訂主角描述，內建八種人設快速選擇
- 🎬 **鏡頭細節**：8 種鏡頭運動 × 7 種光線 × 8 種情緒色調

## 🚀 使用流程

1. **挑風格** — 從 12 種日系視覺語彙挑一個
2. **選場景** — 日本標誌性地點 × 四季其中之一
3. **定故事** — 選擇故事類型與主角描述
4. **調鏡頭** — 鏡頭運動、光線、情緒
5. **生成** → 立即產出三幕劇影片提示詞，貼到 AI 工具即可

## 🛠 技術

- 純 HTML / CSS / JavaScript，無外部相依
- 單一檔案可離線使用
- 響應式設計，手機平板皆可

## 💡 設計靈感

提示詞結構遵循 [Google DeepMind Gemini Omni 官方建議的六核心要素](https://deepmind.google/models/gemini-omni/prompt-guide/)：
鏡頭 (Shot framing) → 風格 (Style) → 光線 (Lighting) → 場景 (Location) → 動作 (Action) → 世界知識 (World knowledge)。
